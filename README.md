## Files

- `404.html` — copy of index.html. GitHub Pages does NOT use `_redirects`, so 404.html is what shows the same page for /whatsapp, /video, /offer, /hello.
- `_redirects` — for Cloudflare Pages / Netlify only, kept here for reference. GitHub Pages ignores it.

## Deploy on GitHub Pages — free

1. Sign in to https://github.com/ with grow.x011@gmail.com (create a free account if needed, no card).
2. Create a NEW PUBLIC repository named `saharan1-links`.
3. Upload `index.html` and `404.html` to the main branch, root folder.
4. Go to Settings → Pages → Branch: main, Folder: / (root) → Save.
5. Wait 2–10 minutes. Live URL will be:
   `https://YOUR-USERNAME.github.io/saharan1-links/`
   Replace YOUR-USERNAME with the GitHub username.

## Easy change — how the user can edit later

No software needed, mobile also works:

1. Open the repo on github.com.
2. Click `index.html`, then the pencil Edit icon.
3. Change what you need, for example a link.
4. Click Commit changes.
5. Do the SAME change in `404.html` too, so /whatsapp etc. keep showing the updated page.
6. Wait 5–10 minutes, the live site updates by itself.

Tip: keep index.html and 404.html identical after every change.
